# Todo App — Vanilla JavaScript

Простое и модульное приложение **To-Do List**, реализованное на чистом JavaScript (ES Modules) без фреймворков.  
Позволяет создавать, редактировать, фильтровать, сортировать и удалять задачи с сохранением состояния в `localStorage`.

---

## Основные возможности

-   **Добавление задач** — ввод новой задачи и мгновенное отображение в списке.
-   **Отметка выполнения** — одно нажатие, чтобы отметить задачу выполненной.
-   **Редактирование задач** — двойной клик открывает поле редактирования, изменения сохраняются автоматически.
-   **Удаление и восстановление** — реализована «корзина» с возможностью восстановления.
-   **Фильтрация** — _все / активные / выполненные_ задачи.
-   **Сортировка** — подготовлена возможность сортировки по имени или дате.
-   **Счётчик задач** — показывает количество отображаемых элементов.
-   **LocalStorage** — все данные сохраняются между сессиями браузера.
-   **Интерфейс** — адаптивный дизайн, интуитивная работа и авто-высота поля при редактировании.

## Архитектура проекта

Приложение построено по модульному принципу с чётким разделением логики:

src/
├── index.html # Основная страница приложения

## Формат данных задачи

```js
{
  id: "uuid-12345",          // Уникальный идентификатор
  text: "Купить молоко",     // Текст задачи
  completed: false,          // Статус выполнения
  taskCreatedAt: 1730541132451 // Время создания (timestamp)
}
```

## Логика работы приложения

**Инициализация:**
app.js вызывает storage.init(), который загружает данные из localStorage.
**Рендеринг:**
renderTasks.mjs визуализирует задачи и корзину.
**Пользовательские действия:**
Обрабатываются централизованно в eventHandler.mjs (нажатия, двойной клик, фильтры и т.д.).
**Сохранение:**
Все изменения моментально записываются в localStorage через storageServies.mjs.
**Обновление интерфейса:**
После любого действия обновляется список, счётчик и текущее состояние фильтров.
